mend is one patch tool for every AI edit format: it applies an edit an AI model wrote to a tree of text files, reading unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON tool-call edits, finding the lines each edit names with tolerant three-tier matching and writing every change or none.

## Run it

```sh
node main.ts patch.diff
```
